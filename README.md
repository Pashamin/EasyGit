**EasyGit** — это легковесный и быстрый менеджер для скачивания (клонирования) Git-репозиториев с открытым исходным кодом, написанный на C# Windows Forms с использованием библиотеки `LibGit2Sharp`.

Программа создана для тех, кто хочет быстро выкачать нужный проект с GitHub без необходимости устанавливать тяжелый консольный Git или разбираться в командах терминала.

## Форки и копирование кода

Проект является полностью открытым, и вы можете свободно делать форки (fork) или использовать этот код в своих наработках. Единственная просьба: **при создании форка или копировании частей кода, пожалуйста, указывайте ссылку на оригинальный репозиторий проекта EasyGit.** Мне будет очень приятно, а другим разработчикам поможет найти первоисточник!

## ✨ Особенности и фичи

* **Простота в один клик:** Вставил ссылку, выбрал папку — и готово.
* **Умная очистка ссылок:** Программа сама вырезает команду `git clone` и убирает любые случайные пробелы и переносы внутри текста.
* **Полноценные настройки:** Отдельное окно конфигурации, где можно включить или выключить автоматическое открытие папки в Проводнике после загрузки.
* **Сохранение параметров:** Выбранные настройки не сбрасываются после перезапуска программы.
* **Человечные ошибки:** Все страшные английские логи от Git автоматически переводятся на понятный русский язык (проблемы с интернетом, VPN, приватные репозитории и т.д.).

## 💻 Инструкция по сборке проекта

Если вы хотите запустить или доработать проект у себя на компьютере:

1. Склонируйте этот репозиторий или скачайте архив с исходным кодом.
2. Откройте файл решения **`EasyGit.sln`** через **Visual Studio** (рекомендуется версия 2022 и новее).
3. Убедитесь, что в менеджере пакетов NuGet установлена библиотека **`LibGit2Sharp`**.
4. В верхней панели Visual Studio переключите конфигурацию сборки с `Debug` на **`Release`**, а платформу — на **`x64`** (библиотека LibGit2Sharp требует четкого указания разрядности).
5. Нажмите `Ctrl + Shift + B` или выберите **Сборка -> Пересобрать решение**.
6. Заберите готовую программу по пути: `EasyGit/bin/x64/Release/`.

> ⚠️ **Важно для работы:** При переносе готового `.exe` файла на другой компьютер, обязательно забирайте вместе с ним файлы `LibGit2Sharp.dll`, `EasyGit.exe.config` и папку `lib`, иначе приложение не запустится.
